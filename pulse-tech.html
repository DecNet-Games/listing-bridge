包依赖与要求：

  • 核心依赖：无（编译与运行不需要任何强制外部包）。
  • 包架构：完全模块化的程序集定义（DecnetGames.JuiceSystem.Runtime、DecnetGames.JuiceSystem.Editor、DecnetGames.JuiceSystem.Demo）。
  • 可选集成（通过预处理器符号自动检测）：
  • TextMeshPro (com.unity.textmeshpro)：可选。安装时自动启用高分辨率浮动战斗伤害弹窗。未安装时启用标准回退。
  • Cinemachine (com.unity.cinemachine)：可选。自动挂接 Cinemachine 虚拟相机实现冲量噪声震动。未安装时启用标准相机回退。
  • Universal Render Pipeline (com.unity.render-pipelines.universal)：可选。URP 激活时自动连接屏幕抓取与音量覆盖（色差、泛光、镜头畸变）。
  • Post-Processing Stack v2 (com.unity.postprocessing)：可选。完整支持 Built-in 渲染管线后期处理体积。
  • Input System (com.unity.inputsystem)：可选。自动支持新版 Unity Input System 手柄震动，同时保留旧版输入兼容性。
